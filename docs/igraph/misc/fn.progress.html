Function progress 

Source 
pub fn progress(message: &str, percent: f64) -> Result<()>
Expand description

Reports progress to the installed progress handler of the calling thread, exactly as igraph’s own functions do; a no-op when no handler is installed. Useful to let long running Rust code built on this crate share the same progress reporting channel.

Binds igraph_progress.

§Errors

ErrorKind::Interrupted if the handler asked to stop; ErrorKind::InvalidValue if message contains a NUL byte.
