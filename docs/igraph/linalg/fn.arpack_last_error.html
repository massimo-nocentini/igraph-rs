pub unsafe fn arpack_last_error() -> ArpackError

The error code of the last ARPACK failure in the process (igraph_arpack_get_last_error).

Prefer ArpackError::from_error, which reads the same information from the returned error in a thread-safe way.

Binds igraph_arpack_get_last_error.

§Safety

In igraph 1.0.0 and 1.0.1 the last ARPACK error is kept in a plain, process-wide C variable (not thread-local, unlike the rest of igraph’s state), written by every failing ARPACK run. The caller must make sure that no other thread runs an ARPACK-based igraph computation concurrently (this includes the eigensolvers and spectral embeddings of this module and ARPACK-based functions of other modules, such as eigenvector centrality); otherwise the read is a data race.
