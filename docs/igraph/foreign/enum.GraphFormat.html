Expand description

Graph file formats known to igraph, for the format-agnostic Graph::read_graph and Graph::write_graph.

The variants list the file extensions recognized by from_path; can_read and can_write tell which direction the generic functions support.

Variants§

§

Edgelist

Plain edge list of 0-based vertex ids (.txt, .edgelist, .edges, .el).

§

Ncol

NCOL symbolic edge list (.ncol).

§

Lgl

LGL format (.lgl).

§

Pajek

Pajek (.net, .pajek).

§

GraphMl

GraphML (.graphml, .xml).

§

Gml

GML (.gml).

§

DimacsFlow

DIMACS flow format (.dimacs, .max); only Graph::read_graph supports it generically (it discards the problem data).

§

GraphDb

Binary ARG graph database format (.graphdb, and the .A00….A99, .B00….B99 suffixes of the database’s graph pairs); read only.

§

Dl

UCINET DL (.dl); read only.

§

Dot

Graphviz DOT (.dot, .gv); write only.

§

Leda

LEDA native format (.gw, .leda); write only.

impl GraphFormat

Source

pub fn from_path(path: impl AsRef<Path>) -> Option<Self>

Guesses the format from the extension of path (case insensitive), or None if the extension is unknown.

use igraph::foreign::GraphFormat;
assert_eq!(GraphFormat::from_path("karate.GML"), Some(GraphFormat::Gml));
assert_eq!(GraphFormat::from_path("/tmp/g.net"), Some(GraphFormat::Pajek));
assert_eq!(GraphFormat::from_path("noext"), None);
