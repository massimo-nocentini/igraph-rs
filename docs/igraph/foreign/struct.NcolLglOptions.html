Expand description

Options of the NCOL and LGL readers (Graph::read_graph_ncol, Graph::read_graph_lgl).

The defaults are: store names, add weights only if present in the file, undirected graph (the LGL software only handles undirected graphs).

names and weights only matter once the attribute handler is enabled with attributes::enable (see the module docs); without it they are harmless.

§Examples

use igraph::{foreign::NcolLglOptions, prelude::*};
let opts = NcolLglOptions::default().with_directed(true).with_weights(AddWeights::No);
assert!(opts.names && opts.directed);
let g = Graph::read_graph_ncol_from_str("a b 2\nb c 3\n", &[], &opts).unwrap();
assert!(g.is_directed());
assert_eq!(g.edge_list(), vec![(0, 1), (1, 2)]);

Fields§

§names: bool

Whether to store the symbolic vertex names as the name string vertex attribute.

§weights: AddWeights

Whether to store the edge weights as the weight numeric edge attribute: AddWeights::Yes always (edges without a weight get 1), AddWeights::IfPresent only if at least one weight is given in the file (again with 1 for the others), AddWeights::No never.

§directed: bool

Whether to create a directed graph: the formats carry no information about directedness.
