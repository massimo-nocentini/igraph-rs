Source
Expand description

Raw FFI bindings to the igraph C library, generated by bindgen at build time from the installed headers.

Everything here is re-exported at the crate root as well, so that igraph::igraph_t and igraph::ffi::igraph_t are the same type. The Rusty API is built on top of these very types: e.g. Graph is an alias of igraph_t enriched with safe methods, and owned types such as VectorInt free their memory on drop.
